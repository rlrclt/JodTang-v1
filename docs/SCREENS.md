# หน้าจอ v1 — แผนการสร้าง (JodTang)

ไฟล์นี้ตอบคำถาม "จะสร้างหน้าไหน อะไรยังไง ลำดับไหน" · ขอบเขต/กติกาอยู่ที่ `docs/PLAN.md`
สถานะ: แผน (ยังไม่ใช่สเปกดีไซน์) — ค่าหน้าตาจริงจะมาใน `docs/DESIGN.md` หลังเลือกแนวจากภาพ

## หลักการ 4 ข้อ

1. **ลำดับ = "หน้าที่คนอื่นต้องใช้ต่อ" ก่อน** → ล็อกอิน → โครงแอป → ชั้นข้อมูล → หน้าที่ผู้ใช้เจอบ่อย → วิเคราะห์ → ตั้งค่า
2. ทุกหน้าอยู่ใต้ **app shell เดียว** (แถบแท็บล่าง 4 แท็บ + FAB) ยกเว้น `/login` และ `/offline`
3. ทุกหน้ามี 3 สถานะครบ: **ว่าง / กำลังโหลด (skeleton ที่โครงตรงของจริง) / error + ปุ่มลองใหม่**
4. **ห้าม hardcode สี/ระยะ/radius ใน component** — อ้างโทเคนใน `src/app/globals.css` เท่านั้น เพื่อให้สลับธีม/DESIGN.md ได้โดยไม่แก้ component

## ลำดับเปิดการ์ด (wave)

- **wave 1 (ตอนนี้)**: `#1` SignIn + auth plumbing · `#2` app shell · (fix lint ที่รันอยู่)
- **wave 2**: `#3` ชั้นข้อมูล+helper เงิน → แล้ว `#4`+#5 หน้าแรก + sheet กรอกเร็ว
- **wave 3**: `#6` รายการทั้งหมด · `#7` สรุป
- **wave 4**: `#8`–`#13` ตั้งค่า (แยกการ์ดตามงาน ไม่รวมก้อนเดียว) · `#14` profile
- **wave 5**: `#15` AI (รอ provider) · `#16` PWA polish · `#17` onboarding

## กติกาที่ทุกหน้าต้องเชื่อฟัง

- เงิน: เก็บเป็น **bigint สตางค์** · แสดงผลผ่าน `formatSatang()` เท่านั้น · ห้ามหาร 100 กระจายในโค้ด
- ตัวเลขที่แสดงต้องมาจากยอดเดียวกันทั้งแอป (หน้าแรก/รายการ/สรุป ของเดือนเดียวกันเท่ากัน) — ไม่ตรง = บั๊ก
- แยกความหมายด้วย `+`/`−` และคำกำกับเสมอ ไม่พึ่งสีเดียว · tap target ≥ 44px · ไม่มี modal กลางจอ · ไม่มี page reload
- ทุกหน้าที่แตะเงิน/สิทธิ์ ต้องผ่าน **review → qa** ก่อนปิดการ์ด
- **SignIn ต้องพิสูจน์ด้วยของจริง**: หน้าและโครง session ทำได้ทันที แต่ "ล็อกอินจริงสำเร็จ" ต้องมีคนกดปุ่มหนึ่งครั้งในเบราว์เซอร์ → มีการ์ด qa แยกที่รอขั้นนี้ (ห้ามอ้างว่าล็อกอินผ่านโดยไม่มีหลักฐาน)
