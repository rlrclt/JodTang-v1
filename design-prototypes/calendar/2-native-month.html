ตัวอย่างหน้าแรก

แตะกล่องเดือน → เบราว์เซอร์เปิด picker เลือกเดือนเองให้ (iOS Safari จะมาเป็นล้อหมุน / Android เป็น grid)

ข้อดี
  • ฟรี ไม่ต้องเขียน code เอง — แค่ `<input type="month">`
  • เข้าถึงได้ (accessibility) กับคีย์บอร์ดเต็มที่
  • ไม่มี bug เรื่องภาษา/ปีไทย เพราะใช้ native
ข้อจำกัด
  • หน้าตาเป็นของแต่ละเบราว์เซอร์ ควบคุมสไตล์ไม่ได้ (iOS ต่างกับ Android)
  • ใน iOS Safari จะแสดงเป็นเดือนแบบ "ปิ๊กเกอร์ ปี" ที่ต้องกด 2 ชั้น กว่าจะได้เดือน
  • ไม่รองรับการเลือก "วัน" ทำได้แค่เดือน
